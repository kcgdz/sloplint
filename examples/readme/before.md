# 🚀 Shrinkray ✨

## 🌟 Overview

In today's fast-paced world, developers need tools that keep up. Images are the backbone of the modern web — but optimizing them is often a pain — slow, manual, and error-prone.

Enter **Shrinkray**: a **cutting-edge**, **blazing-fast** CLI that **seamlessly** resizes and compresses your images. It's not just an image resizer, it's a complete optimization powerhouse. Whether you're a solo hacker or a large enterprise, Shrinkray will elevate your workflow and unlock the full potential of your assets.

## ✨ Features

- **Fast:** Leverages cutting-edge algorithms for lightning-fast processing.
- **Robust:** Robust error handling ensures nothing breaks.
- **Flexible:** Supports JPEG, PNG, and WebP — and more on the way.
- **Seamless:** Integrates seamlessly into your existing pipeline.
- **Powerful:** Unleash the power of batch processing.

## 📦 Installation

Getting started is effortless! Let's dive in:

```bash
npm install -g shrinkray
```

## 🛠️ Usage

Simply point Shrinkray at a folder and watch the magic happen! It's worth noting that Shrinkray utilizes all available CPU cores to deliver unparalleled performance.

```bash
shrinkray ./photos --width 1200
```
