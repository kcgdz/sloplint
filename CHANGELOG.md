# Changelog

## 0.2.0 (2026-11-01)

- Add 54 phrase rules for Turkish, Spanish, French, German, Portuguese, Italian, Dutch, Russian and Arabic, with explanations in each language.
- Check mixed-language documents without a language flag; 93 rules in total.
- Make the playground editor easier to find, keep long drafts in a scrollable area, and improve finding disclosures and keyboard focus.
- Preserve cleared drafts on reload and keep the example picker in sync with edits.
- Match the social preview image to the playground's dark theme.
- Clarify that a clean score does not determine who wrote a text.

## 0.1.0 (2026-10-31)

First release.

- CLI with stylish, JSON and GitHub Actions output, a 0 to 100 slop score, and `--badge`.
- 39 rules in seven categories, each with flagged and non-flagged examples.
- `.sloplintrc` config, per-rule options, and inline `sloplint-disable` directives.
- Claude Code plugin with the `sloplint` skill and six type-specific writing guides.
- Browser playground.
